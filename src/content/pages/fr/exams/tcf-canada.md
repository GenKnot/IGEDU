Le **TCF Canada** est l’autre examen de français reconnu par IRCC pour l’immigration fédérale, avec la même valeur que le [TEF Canada](/exams/tef-canada). Il est organisé par France Éducation international.

## L’essentiel

| | |
|---|---|
| Usage | Immigration au Canada (fédéral) |
| Épreuves | Les quatre sont obligatoires : compréhension orale, compréhension écrite, expression écrite, expression orale |
| Durée | Environ 2 h 45 |
| Expression orale | 12 minutes en trois parties, dont une prise de parole improvisée, sans préparation |
| Résultats | Environ 3 semaines |
| Validité | 2 ans |
| Points d’immigration | Oui, selon le NCLC obtenu |

Le TCF compte plus de questions et le temps y est serré. Si vous craignez de manquer de temps, c’est le point à travailler.
