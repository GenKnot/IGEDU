**TEF Canada** is one of the two French tests IRCC accepts for federal immigration (Express Entry), with exactly the same value as [TCF Canada](/exams/tcf-canada). It is run by the CCI Paris Île-de-France.

## The essentials

| | |
|---|---|
| Use | Immigration to Canada (federal) |
| Sections | All four are required: listening, reading, writing, speaking |
| Length | About 3 hours |
| Speaking | 15 minutes in two parts |
| Results | About 2 to 3 weeks |
| Validity | 2 years |
| Immigration points | Yes, based on the NCLC level obtained (NCLC 7 is the key threshold) |
