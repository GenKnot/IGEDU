**TCF Canada** is the other French test IRCC accepts for federal immigration, with the same value as [TEF Canada](/exams/tef-canada). It is run by France Éducation international.

## The essentials

| | |
|---|---|
| Use | Immigration to Canada (federal) |
| Sections | All four are required: listening, reading, writing, speaking |
| Length | About 2 h 45 |
| Speaking | 12 minutes in three parts, including an impromptu talk with no preparation |
| Results | About 3 weeks |
| Validity | 2 years |
| Immigration points | Yes, based on the NCLC level obtained |

TCF has more questions and tighter timing. If running out of time worries you, that is what to train.
